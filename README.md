# ERP-PROJECT

Project management artifacts for the CharterOps ERP revamp (Jan–Mar 2026): charter, WBS, RACI, risk register, change log, sprint reports, UAT, release plan, status reports and closure report. Hybrid Agile + Waterfall, tracked in ClickUp.

CharterOps is an ERP system for executive aviation and charter flight operations. The project stabilized its core workflows, fixed 12 P1 defects, released the internal app to production and built branded landing pages for partner operators Qair and Viva Jets. It ran from January 5 to March 31, 2026, led by Maryam Abubakar and managed by Morenikeji Bankole.
