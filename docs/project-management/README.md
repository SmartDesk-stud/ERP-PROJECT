CharterOps is an ERP system for executive aviation and charter flight operations. This folder holds the project management artifacts for the revamp project: stabilizing core workflows, modernizing the UI, fixing billing and validation defects, releasing to production, and building branded landing pages for partner operators Qair and Viva Jets.

Planning artifacts are written as they stood at the time of issue; documents with a "final" version also record the actual outcomes.
